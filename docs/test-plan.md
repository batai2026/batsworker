# OpenWorker 用户综合测试大纲

版本：1.0.1　编制日期：2026-11-08

## 0. 使用说明

- **优先级**：`P0` = 每次发版必测（冒烟，约 20 分钟）；`P1` = 核心功能，全量回归必测；`P2` = 边缘路径，按需抽测。
- **用例格式**：`ID | 场景 | 关键步骤 | 预期结果`
- **缺陷记录**：模块 / 用例 ID / 复现环境（OS + 版本）/ 复现步骤 / 期望 vs 实际 / 截图或日志（`%APPDATA%\coworker\logs\openworker-server.log`）

### 测试环境准备

| 项 | 要求 |
|---|---|
| 平台 | Windows 10/11 x64、macOS（arm64 与 x64 各一台） |
| 模型 | 至少 1 个云端（如 DeepSeek/OpenAI）+ 1 个本地（Ollama） |
| 网络 | 正常网络 + 一次断网/代理场景 |
| 工作区样本 | ① 非 git 空目录 ② 含中文提交的 git 仓库 ③ 含深层目录与大文件的项目 |
| 账号 | 未登录（本地态）+ 已登录云端（若测云端能力） |

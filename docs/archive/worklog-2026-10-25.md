## 1. 登录与否差异分析

对 OpenWorker 的「登录（OpenWorker Cloud）与否」做了全库分析，结论：

- **不登录完全可用**：手动粘贴模型 key 与连接器 token 即可运行全部核心功能。
- **登录专属能力**：① 一键 OAuth 连接（`begin_managed_connect`，token 本地存储、云端自动刷新）；② Slack/GitHub 云中继（relay WebSocket 用云 JWT 认证，入站事件经一条云 WS 推送，回复直连第三方 API）；③ Persona 商店（浏览/安装云端 Persona）；④ 产品遥测（默认开、可关）。
- 登录后手动路径依然保留，不会被收回。
- 详细解说见会话记录；相关源码：`coworker/cloud.py`、`coworker/server/app.py`、`coworker/server/manager.py`、`surfaces/gui/src/components/{Sidebar,GalleryModal,ManageTabs}.tsx`。

## 2. 功能一：演示生成技能 + 内置浏览器面板

### 2.1 演示 → 生成技能（「录制演示 → 生成技能」）

- 后端 `coworker/skills/demo.py`：把**粘贴步骤**（每行一步）或**浏览器操作录制**（`browser-replays/*.json`）确定性转换为 `SKILL.md`（YAML frontmatter + Steps + Guidelines）。
- 走与上传相同的 **staged 安装路径**（生成 → 预览 → 确认），技能带 `demo` 来源徽标。
- 接口：`POST /v1/skills/demo`、`GET /v1/browser/recordings`。
- GUI：Settings ▸ Skills ▸「Record a demo」入口（粘贴步骤 / 选择浏览器录制）。

### 2.2 内置浏览器面板

- `RightRail.tsx` 新增 **Browser** 区块：实时截图、URL/标题、状态、最近动作/错误，支持截图刷新、系统浏览器打开、关闭浏览器；每 2 秒轮询 + 工具调用时即时刷新；首次活跃自动展开。

## 3. 功能二：自动化模板市场 + 连接器/插件开放生态

### 3.1 自动化模板市场（对标 Cursor Automations）

- `coworker/automation/templates.py`：10 个内置模板（含 4 个新工程/安全模板），元数据驱动。
- 接口：`GET /v1/automations/templates`、`POST /v1/automations/templates/{key}/instantiate`（一键创建，写模板自动带 `send_message → 频道` 常驻授权）。
- GUI：`TemplateMarketplace.tsx`（搜索 + 分类筛选 + 卡片网格 + 配置面板）。

### 3.2 连接器/插件开放生态（对标 Claude Marketplace）

- `coworker/connectors/marketplace.py`：**精选 MCP 服务器**（Granola、Linear，一键添加即得工具）+ **社区插件**（JSON 描述符，安装注册为连接器卡片，持久化到 `connector-plugins/`，重启自动恢复）。
- 接口：`GET /v1/connectors/marketplace`、`POST /v1/connectors/marketplace/plugins/{name}/install|uninstall`。
- GUI：`MarketplaceModal.tsx`（连接器页「⋮ Marketplace」按钮，MCP 服务器 / 社区插件两个标签页）。

## 4. 功能三：明文记忆 + 多端一致 + 并行子代理

### 4.1 明文可编辑记忆（对标 Lindy Memory）

- `coworker/memory/markdown.py`：记忆导出为 `MEMORY.md`（按 Global / Workspace / Session 分组），编辑后**按分区替换**重新导入（文件即真相）。
- 接口：`POST /v1/memory/export|import|reveal`。
- GUI：Settings ▸ Memory ▸「Plain-text memory」卡片（导出 / 显示文件夹 / 重新导入）。

### 4.2 多端一致（对标 Claude Cowork / Cursor）

- PWA：`manifest.webmanifest` + SVG/PNG 图标 + `index.html` 元信息（theme-color、apple-mobile-web-app-capable、apple-touch-icon 等），可「添加到主屏幕」以独立窗口打开。
- 移动端 CSS：≤900px 右侧栏变全高浮层、`100dvh`；≤640px 收窄侧边栏、放大输入字号避免 iOS 聚焦缩放。
- 未加 Service Worker（避免与 sidecar token 引导冲突），已注明为后续项。

### 4.3 并行子代理与任务分块（对标 Cursor / Claude Cowork）

- `coworker/tools/subagent.py` 新增 **`delegate_parallel`**：接收 `subtasks: [{name, task}]`，为每个子任务创建只读子代理引擎，`ThreadPoolExecutor` **并行执行**，按名字聚合返回。
- 注册到 `subagents=True` 的 agent；进度面板显示「Running subagents in parallel…」。

## 5. 功能四：威胁模型闭环 + 角色化雇佣落地页

### 5.1 可编辑威胁模型 + 验证闭环（对标 Claude Security）

- `coworker/security/__init__.py`：威胁模型（`threat-model.md`，团队可编辑，默认模板含 In scope / Out of scope / Reachability / Mitigations）+ 发现跟踪（`findings.json`，`open → fixing → fixed → closed` 并关联 PR）。

- 以 `security` 能力注册进 catalog，并加入 7 个安全类 Persona 的 `tools:`。
- 接口：`GET/PUT /v1/security/threat-model`、`GET/POST /v1/security/findings`、`PATCH/DELETE .../findings/{id}`。
- GUI：Settings ▸ **Security** 标签页（威胁模型编辑器 + 发现跟踪器）。

### 5.2 角色化「雇佣」落地页（对标 Lindy /hire）

- 每张卡展开为落地页：**What it does / Checks in / Never / Works with** + 「Meet the coworker →」直达 Persona 详情页。

## 7. 遗留事项与后续建议

1. **桌面屏幕录制 → 自动生成技能**：当前「录制」指浏览器操作录制；OS 级录屏 + 转录是后续扩展。
2. **浏览器 cookie 导入 / 多会话隔离**：当前浏览器为单例会话；可加 cookie 导入与多 profile。
3. **云端模板/插件目录**：当前目录为内置；可仿照 Persona Gallery 接入 OpenWorker Cloud。
4. **PWA Service Worker**：解决 sidecar token 引导后加入，实现离线打开与完整安装体验。
5. **PR 合并自动检测**：轮询 GitHub PR 状态，merged 后自动把发现标记为 `fixed`，让验证闭环真正自动化。
6. **威胁模型按项目隔离**：当前为全局一份；可改为跟随仓库（`<workspace>/.coworker/threat-model.md`）。
